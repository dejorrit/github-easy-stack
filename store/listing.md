## Description

GitHub Easy Stack groups stacked pull requests in GitHub's pull request lists.

— Always grouped: stack members are shown together under a stack header, even when other PRs sit between them. Open members that aren't on the current page appear as compact placeholder rows.
— Progress at a glance: a donut on each header splits the stack into merged, ready, in progress, blocked, draft and not on this page. Hover it for the counts.
— What to do next: the header also shows the lowest member that hasn't merged, who the stack belongs to, and how old it is.
— Fold: click a stack header to fold or unfold it, or fold all stacks by default from the toolbar popup.
— Rail: a colored line connects the members of a stack; hover any row to highlight its whole stack.

A PR counts as ready when it has no requested changes, no failing checks and isn't a draft.

Privacy: no external requests. Stack data is read through your existing GitHub session on github.com, and the only permission used is storage — for your fold preferences.
