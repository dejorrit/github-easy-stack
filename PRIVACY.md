# Privacy policy

GitHub Easy Stack does not collect, store, sell or share any personal data.

## What the extension does with data

- **Pull request information.** On github.com pull request lists, the extension reads which pull requests belong to the same stack, plus their titles and states. It requests this information from github.com itself, using your existing GitHub session. The data is only used to arrange and label the list in your browser. It is never sent anywhere else.
- **Preferences.** Your fold settings (whether stacks are folded by default, and which stacks you folded or unfolded) are saved with Chrome's storage API. The default setting is synced through your Chrome profile. Nothing else is stored.

## What the extension does not do

- No analytics, tracking or telemetry.
- No requests to any server other than github.com.
- No access to your GitHub token, password or other credentials.
- No remote code.
